# 墨耕 · 书案 —— 界面重设计说明

这一版把界面从「三栏写作台 + 独立改编台」重做成**一间书案**：左侧一条书脊（书脊上是这本书的名字，竖排），中间是纸，右边是副驾（AI 助手）。所有功能围绕一个动作组织——**把这一章写下去**。

截图见 `docs/screens/`（桌面 1440×900、平板 834×1112、手机 390×844）。

## 一、结构

```
书脊 54px │ 顶栏（书名 / 章名 / 字数 / 存稿态 / 模型 / 昼夜 / 设置）
          │
          ├── 案头：书稿卡片、通用素材库、原料库、废纸篓
          ├── 写作台：章目栏 290px │ 纸 46rem │ 副驾 358px
          └── 改编台：章目 │ 改编方向 + 台账 + 改编稿
```

- **书脊**：五个按钮（案头 / 稿纸 / 素材 / 大纲 / 副驾），当前所在的位置亮起来；书名竖排，像书脊上的烫字。
- **顶栏**：面包屑（书名 / 章名 /「改编」角标）、实时字数、存稿态（正在写… / 未存 / 已存）、运行指示（正在写的那一轮，可停）、命令面板、昼夜、设置。
- **纸**：宋体正文、33em 行宽、行高 1.95，两侧留白，「先看见纸，再看见工具」。
- **副驾**：三个身份（执笔者 / 设定官 / 润色），一个对话框，流式输出、工具调用、思考过程、提问卡都能就地展开。

## 二、八个界面

| 界面 | 看什么 |
| --- | --- |
| 案头 `#view-desk` | 书稿卡片（进度条按目标字数算）、通用素材库（跨书复用，显示被几部书借用）、原料库（epub/pdf/txt 切章入库）、废纸篓 |
| 稿纸 `paper` | 章目栏（进度环、筛选、搜索、按卷分组）、纸（标题 / 字数 / 第几版 / 挂了哪些料）、写作动作（续写 / 润色 / 重写 / 起稿） |
| 素材 `materials` | 本章已挂的料（可摘）、种类筛选（13 种，可自定义）、卡片（挂到本章 / 编辑 / 存进库 / 删除） |
| 大纲 `outline` | 卷与章的账本：序号、章名、视角、挂了料、纲、状态（待列纲→定稿六档）、字数 |
| 改编台 `#view-adapt` | 原书章目 → 改编方向 → 本章台账（人物 / 人设 / 情节 / 视角 / 增补 / 语感）→ 提案（采用才落盘） |
| 命令面板 `⌘K` | 所有动作都可搜到；↑↓ 选、Enter 走、Esc 收 |
| 设置 | 模型与联网检索、供应商（内置 + 自建，可拉模型）、阅读偏好（字号 / 行距 / 打字机）、数据（落盘状态、快照、导入导出 .novel）、关于 |
| 履历抽屉 | 这一章的旧版本（可看、可恢复）+ 写过的几席（接着上一席说） |

## 三、这一版新加的东西

1. **接着写**：进书时自动挑「有正文但未成稿」的章；没有就落到第一个空章，并给出「让执笔者起稿 / 我自己写」两个入口。
2. **一键样书**：案头空态可以直接铺一本《夜航船》（4 条素材 + 4 章纲 + 首章正文），三十秒看清这套东西怎么用。
3. **全局运行指示**：写作 / 对话 / 润色 / 改编都在跑，顶栏那颗朱点能停；断线不丢，`/api/runs/:id/stream?since=` 能接回来。
4. **断线翻译**：服务重启时不再甩英文栈，改说「服务没接上，稿子都还在」，并自动重试四次。
5. **素材种类管理**：13 种内置之外可增删改，删掉的料归到「其他」。
6. **润色选区**：选中正文再润，服务端带 `revision + expectedText` 校验，别人改过就提示重选。
7. **改编台账**：一章一页账，提案先看后采用，采用时用 `baseRevision` 防覆盖。
8. **打字机模式**：光标那一行停在纸中间（设置里可关）。
9. **窄屏三件套**：章目变左抽屉、副驾变底抽屉、稿纸工具条折成两行；遮罩只收浮层，宽屏副驾是常驻列。
10. **昼夜**：纸色 / 墨色 / 朱砂 / 青玉四组令牌整体翻转，暗色下纸不是纯黑，是夜里的一张宣纸。

## 四、验证

- `npm run test:frontend` 44 项（启动顺序、挂点、令牌纪律、暗色覆盖、字高链、流式协议、改编不落盘、润色校验、断线重连）
- `npm run test:server` / `npm run test:tauri` / `pnpm test` 全绿
- jsdom 端到端冒烟：启动 → 开书 → 切章 → 自动存稿 → 料 / 纲 / 副驾 / 命令面板 / 设置 / 履历 / 专注 / 改编，`errors: []`
- 真实 Edge（headless CDP）三端截图，逐张看过并修掉：稿纸页签映射、库列表不加载、遮罩压住抽屉、大纲五列在手机上溢出、设置滑块默认蓝、抽屉不满屏、卷头数字粘连等 20 余处。

## 五、怎么跑

```bash
npm run dev          # 本地单机，http://127.0.0.1:8787
npm run build:web    # 出 dist/web（含浏览器端本地 API）
npm run dev:tauri    # 桌面壳
```
